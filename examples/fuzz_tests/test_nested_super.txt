// ============================================================================
// Test: Nested Numeric Exponents (Expanded to Multiplication)
// ============================================================================
// Demonstrates:
//   - Numeric exponentiation expanded to repeated multiplication
//   - Nested powers (square-then-cube) without the ^ operator
//   - Set comprehension with complex expressions
//
// Why: Z/fuzz has no numeric exponentiation operator. ^ in Z is
// relational iteration (Z RM Section 4.4), so a numeric x^2 fails
// fuzz type checking. Inside a fuzz-checked box, write the square
// and cube out as repeated multiplication instead.
//
// Features:
//   - z * z [basic square, in place of z^2]
//   - (z * z) * (z * z) * (z * z) [nested power: (z^2)^3 expanded]
//   - Set comprehension with bullet separator
//
// See: docs/USER_GUIDE.md - Sections "Arithmetic Operators", "Set Comprehensions"
// See: docs/guides/FUZZ_VS_STD_LATEX.md - "Numeric Exponentiation Is Not a Z Operator"
// ============================================================================

=== Test Nested Exponent, Expanded to Multiplication ===

{ z : Z | z mod 2 = 0 . (z * z) * (z * z) * (z * z) }
